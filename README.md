# Client builds

Client builds for the test server, published by CI from the client repository. Each release holds the builds of one commit; the links below always serve the newest one.

| Platform | Download |
|---|---|
| Windows | [metin-forever-client-windows.zip](https://github.com/metin-forever/releases/releases/latest/download/metin-forever-client-windows.zip) |
| macOS | published here once its build is available |

The Windows client is not signed: on first start, Windows SmartScreen asks for confirmation under "More info".
